# 🚖 UBER DATASET ANALYSIS

## 📌 Project Overview

This project presents a comprehensive Exploratory Data Analysis (EDA) of an Uber-style ride-sharing dataset stored in a file (`rideshare.db`). The analysis focuses on understanding user behavior, driver activity, trip patterns, customer satisfaction, payment preferences, and cancellation trends.

The project follows a complete data analysis workflow including data loading, data understanding, data cleaning, exploratory data analysis, visualization, business insights generation, and recommendations.

The objective is to extract meaningful insights that can help ride-sharing platforms improve operational efficiency, customer experience, driver engagement, and overall business performance.

---

## 🎯 Project Objectives

* Analyze user and driver distribution across cities.
* Understand trip patterns and ride activity.
* Evaluate driver and rider ratings.
* Identify vehicle brands and models associated with higher ratings.
* Study payment preferences of users.
* Analyze trip cancellations and cancellation reasons.
* Generate business insights and actionable recommendations.

## 📂 Dataset Tables

The project utilizes multiple relational tables from the `rideshare.db` database:

| Table Name    | Description                   |
| ------------- | ----------------------------- |
| Users         | User information              |
| Drivers       | Driver details                |
| Riders        | Rider information             |
| Trips         | Trip records                  |
| Locations     | Pickup and drop locations     |
| Payments      | Payment transactions          |
| Reviews       | Ratings and customer feedback |
| Cancellations | Trip cancellation records     |
